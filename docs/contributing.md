# Contributing

Use a temporary data root for all development and test commands. Never point tests, experiments, or documentation examples at the repository `data/` directory.

Before submitting a change, run the repository Nox gates for linting, typechecking, tests, security, documentation, packaging, and pre-commit. New behavior must preserve point-in-time visibility, durable provenance, and the execution safety boundary.

See the repository-level [contributor guide](https://github.com/56kyle/money-pit/blob/main/CONTRIBUTING.md) and [Code of Conduct](codeofconduct.md).
